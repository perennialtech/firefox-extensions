# Firefox Extensions

Two Firefox extensions maintained in one repository:

- [X Account Location Flags](extensions/x-account-location-flags/README.md) — show X's reported account locations next to account names. [Install signed release](https://github.com/perennialtech/firefox-extensions/releases?q=v).
- [Reddit Direct Images](extensions/reddit-direct-images/README.md) — open Reddit image URLs as native images instead of Reddit's HTML media viewer.

Each extension has its own `manifest.json`, add-on ID, source, and tests under
`extensions/`. They can be installed independently.

For developing, testing, and releasing either extension, see
[CONTRIBUTING.md](CONTRIBUTING.md).
